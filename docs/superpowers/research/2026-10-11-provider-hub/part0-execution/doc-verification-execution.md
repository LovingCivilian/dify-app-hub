### DEVIATES / GAP with the documented alternative

- 1 GAP: documented removal is `pnpm remove mysql2` (removes from package.json, node_modules and rewrites the lockfile). `pnpm install --lockfile-only` is documented only as "only updates pnpm-lock.yaml and package.json"; its pruning of a hand-deleted dependency is undocumented.
- 2a DEVIATES (partly): `--no-env-resolution` only skips service `env_file:` entries, it does not keep `.env` out of `${VAR}` interpolation. The documented way to avoid the owner's `.env` is `--env-file <file>` (alternate environment file); `--no-interpolate` skips interpolation entirely. Keep `--env-file` + `--quiet`; `--no-env-resolution` is only needed because the three compose files declare `env_file:`.
- 3 DEVIATES: use tsconfig `exclude` (set `"exclude": ["node_modules", "tmp"]`; setting it replaces the default list), not an output filter.
- 5g GAP: `DrizzleQueryError.cause` is not in Drizzle's docs; it is in the installed source (drizzle-orm/errors.js/.d.ts). Reading the standard `Error.cause` is the safe form; the code already does so.
- 6c GAP: `DatabaseError.code` and `.constraint` are not on node-postgres.com; they exist in pg-protocol's `messages.d.ts` and map to PostgreSQL's documented ErrorResponse fields (SQLSTATE, constraint name).
- Minor, not verdict-changing: 5f (migrate with a `Pool`: the MySQL page recommends a single client for migrate; the PG page is silent), 7 (docs crawled are Vitest 5.x; installed is 4.1.7, and the repo's explicit `extends: true` makes it correct for both), 8 (unescaped `new RegExp(email)`).
