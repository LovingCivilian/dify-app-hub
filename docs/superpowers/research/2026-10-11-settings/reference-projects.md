# Instance settings in 13 reference projects

How well-known self-hosted projects store instance settings that an admin can set by environment or in an admin UI: the table shape, env versus UI, secrets, branding images and how a change reaches other instances. Condensed from three research agents' reports of 2026-10-11 (each claim was read at the pinned commit). The agents' scratch copies of the files lived under `tmp/settings-research/`, which is not committed; the pinned commits below are the citable form.

Commits: gitlabhq/gitlabhq@3c5db71e, go-gitea/gitea@8a9e8c4e, discourse/discourse@7d3d93e0, keycloak/keycloak@ebde947d, twentyhq/twenty@22ada84, n8n-io/n8n@529b0d1, documenso/documenso@38ecb21, calcom/cal.com@54343aa, payloadcms/payload@b103a85, mattermost/mattermost@47eebd55 (docs mattermost/docs@bd09d959), grafana/grafana@891f7973, open-webui/open-webui@f8ae8a6c (docs open-webui/docs@13dce9fd), makeplane/plane@bab49bb9.

## A — one JSON document per area

- **Grafana** `sso_setting(id uuid, provider, settings TEXT (MEDIUMTEXT on MySQL), created, updated, is_deleted)` (pkg/services/sqlstore/migrations/ssosettings/migrations.go:6-21; pkg/services/ssosettings/models/models.go:47-53). DB keys win, ini/env fill missing keys (ssosettingsimpl/service.go:174-204,750-770); docs: stored settings "override settings from other sources (arguments, environment variables, settings file, etc)" (grafana.com …/api-legacy/sso-settings/). No lock; reset menu hidden for source 'system' (public/app/features/auth-config/ProviderConfigForm.tsx:240). Secrets encrypted via the secrets service (envelope, KEK from `secret_key` or KMS; AES-CFB default, AES-GCM enterprise), base64 (service.go:350-358,553-575; grafana.com …/configure-database-encryption/); write-only: `*********` on read, placeholder on save keeps it (service.go:339,713-727). LDAP UI-editable (service.go:112-114; ssoSettingsLDAP toggle removed 2026-02-03, featuremgmt/toggles-gitlog.csv:336). Branding: enterprise, ini URLs `login_logo`, `fav_icon`. Propagation: in-memory cache, every instance re-reads every `reload_interval` (1m) "useful in high availability setups" (conf/defaults.ini:840-843; service.go:577-596).
- **Mattermost** whole config one JSON doc: `Configurations(Id, Value text, CreateAt, Active UNIQUE, SHA)`, new row per save, skip on same SHA (server/config/migrations/postgres/000001–000003; server/config/database.go:161-220); `ConfigurationFiles(Name PK, Data text, CreateAt, UpdateAt)` for files like SAML certs (000002:1-7; docs configuration-in-your-database.rst:84-86). `MM_*` env overrides at runtime (environment.go:16-27,89-97), stripped before persist (store.go:187-213); server sends a map of env-set fields (environment.go:100-105); UI disables the field with "This setting has been set through an environment variable. It cannot be changed through the System Console." (webapp/channels/src/components/ admin_console/set_by_env.tsx:7-16; text_setting.tsx:20-39). Secrets plaintext in JSON; API masks with 32 `*`, restores on save (public/model/config.go:93,5573-5630; store.go:183-185). Brand image in file backend `brand/image.png` (channels/app/brand.go:18-19,71). Propagation: cluster `ConfigChanged` (enterprise) (channels/app/platform/config.go:120-122).
- **Documenso** (TS; now React Router 7) `SiteSettings { id String @id, enabled Boolean, data Json, lastModifiedByUserId, lastModifiedAt }` (packages/prisma/schema.prisma:1122-1129); one row per area (`site.banner`, `telemetry.installation`), zod union per id (lib/server-only/site-settings/schema.ts:7-15; schemas/banner.ts:5-21); upsert by id (upsert-site-setting.ts:9-27). Branding logo per org/team: string JSON `{type,data}` → DB bytes or S3 (lib/universal/upload/get-file.server.ts:12-18), served with ETag (routes/api+/branding.logo.organisation.$orgId.ts:54-66). Encryption elsewhere: XChaCha20-Poly1305, key sha256 of `NEXT_PRIVATE_ENCRYPTION_KEY` / `_SECONDARY_KEY` (lib/universal/crypto.ts:11-18). Read per request, no cache (\_layout.tsx:32-34).
- **n8n** key/value table `settings(key PK, value string, loadOnStartup bool)` (packages/@n8n/db/src/entities/settings.ts:10-20) but one JSON doc per area: `features.ldap` (cli/src/modules/ldap.ee/ldap.service.ee.ts:103-151), `features.oidc`. Per-area `*_MANAGED_BY_ENV` (e.g. `N8N_SSO_MANAGED_BY_ENV`): env written into the row on every startup, UI locked, save API 403 (@n8n/config/src/configs/instance-settings-loader.config.ts:32-34; loaders/sso/oidc.instance-settings-loader.ts:62-91; oidc.controller.ee.ts:61-65). Secret field encrypted inside the JSON (Cipher.encryptV2, AES-256-CBC, data key wrapped by `N8N_ENCRYPTION_KEY`) (ldap.service.ee.ts:114,138; core/src/encryption/aes-256-cbc.ts:10-39; cipher.ts:54-89); write-only: placeholder on GET, placeholder on save keeps it (redact-ldap-config.ts:4-8; ldap.service.ee.ts:119-124). Multi-main: pub/sub `reload-oidc-config` (oidc.service.ee.ts:634-665). SMTP env-only.
- GitLab's newer areas: 59 per-area `jsonb` columns on `application_settings` (e.g. `rate_limits`, `transactional_emails`) typed by `jsonb_accessor` + JSON schema (app/models/application_setting.rb:983-990,1012-1016). Gitea LDAP sources: `login_source.cfg` JSON TEXT per source (models/auth/source.go:110-126).

## B — typed table(s)

- **GitLab** `application_settings` single wide row, ~596 columns (db/structure.sql:14059-14757), moving new areas into per-area jsonb (above). Branding: typed single-row `appearances` (structure.sql:13995-14032; app/models/appearance.rb:67,79-80), logo and favicon as CarrierWave uploads (appearance.rb:69-72). gitlab.rb seeds defaults on row creation (application_setting_implementation.rb:41ff); some locked with "disabled in your configuration file" (…:643-660; \_usage.html.haml:14-22). LDAP and SMTP gitlab.rb-only. Secrets per column AES-256-GCM `attr_encrypted`, key `db_key_base_32` (application_setting.rb:1177-1184,1210-1248; config/settings.rb:158-170), key rotation (encrypted_attribute.rb:38-50). Cache: per-process 60 s (cacheable_attributes.rb:85-90).
- **Cal.com** `Deployment` single-row (id = 1) typed (`logo`, `theme Json?`, `licenseKey`, `signatureTokenEncrypted`) (packages/prisma/schema.prisma:1295-1305); `App.keys Json?` plaintext, unmasked to admin (saveKeys.handler.ts:21-47; listLocal.handler.ts:46-60); signature token AES-256-CBC with `CALENDSO_ENCRYPTION_KEY` (packages/lib/crypto.ts:3-24).
- **Payload** a table per Global, columns from fields (packages/drizzle/src/schema/buildRawSchema.ts:97-115).

## C — key/value rows

- **Twenty** `core.keyValuePair(key, value jsonb, type CONFIG_VARIABLE, userId/workspaceId NULL)` (key-value-pair.entity.ts:22-27, 115-134); DB overrides env, env fallback (twenty-config.service.ts:56-70), `isEnvOnly` locked (:208-221), `IS_CONFIG_VARIABLES_IN_DB_ENABLED` (config-variables.ts:1454-1461); UI labels source database/environment/default (:223-245), "This database value overrides environment settings" (ConfigVariableHelpText.tsx:62-80). Sensitive encrypted AES-256-GCM, HKDF-SHA256 from `ENCRYPTION_KEY` falling back to `APP_SECRET`, `FALLBACK_ENCRYPTION_KEY` for rotation (config-storage.service.ts:93-107; encrypt-aes-gcm-v2.util.ts:15-25; derive-gcm-key.util.ts:18-29; resolve-encryption-keys-or-throw.util.ts:15-34); UI shows last 4 chars. 15 s cron cache refresh (database-config.driver.ts:119-142).
- **Gitea** `system_setting(setting_key unique, setting_value text JSON, version, created, updated)` (models/system/setting.go:20-32); 6 options in DB (modules/setting/config.go:70-86); DB > app.ini > default (value.go:106-120); admin Configuration page read-only for app.ini, mailer password hidden, test mail (templates/admin/config.tmpl:186-228); LDAP bind password AES-CFB no MAC, key sha256 of SECRET_KEY (services/auth/source/ldap/source.go:36-37,64-87; modules/secret/secret.go:20-65), not write-only (edit.tmpl:64); branding = files in $GITEA_CUSTOM/public/assets/img; revision row checked ≤1/s (setting.go:78-142).
- **Discourse** `site_settings(name unique, data_type, value)` (app/models/site*setting.rb:450-464); `DISCOURSE*\*`globals shadow the setting: hidden and writes ignored (lib/site_setting_extension.rb:1414-1421,1063-1081,411-436); secrets plaintext, masked in the browser (db_provider.rb:27-40; site_setting_extension.rb:528-532); SMTP global-only; logo/favicon are`type: upload`settings (site_settings.yml:155-158,196-199; site_setting.rb:89-93,325-390); MessageBus`/site_settings` refresh (712-741,897-899).
- **Open WebUI** `config(key TEXT PK, value JSON, updated_at)` since Aug 2026, "Replaces the old single-row JSON blob" (backend/open_webui/models/config.py:1-8,100-109); env seeds once, then DB wins (config.py:43-46; models/config.py:247-273); `ENABLE_PERSISTENT_CONFIG=False` → env wins, UI writes memory only (models/config.py:134-148,199-209; docs env-configuration.mdx:22-35); OAuth env-only read-only "These settings are read from environment variables and cannot be edited here while {{ENV_VAR}} is disabled." (Authentication.svelte:586-594); secrets plaintext, LDAP password returned to admin (routers/auths.py:150,1270-1272); direct DB reads.
- **Plane** `instance_configurations(key unique, value text, category, is_encrypted)` (apps/api/plane/license/models/instance.py:72-83); env seeds missing keys at entrypoint (configure_instance.py:28-40); `SKIP_ENV_VAR` (common.py:365; instance_value.py:17-39); Fernet, PBKDF2 of SECRET_KEY with fixed salt (license/utils/encryption.py:13-44); not write-only (serializers/configuration.py:15-21); admin GET cached 2 h in Redis, invalidated on PATCH (views/configuration.py:35-43).
- **Keycloak** `COMPONENT` + `COMPONENT_CONFIG(ID, COMPONENT_ID, NAME, VALUE)` (ComponentConfigEntity.java:36-53); LDAP bindCredential plaintext unless `${vault.key}` (RealmAdapter.java:2205-2220; LDAPStorageProviderFactory.java:172-175); API masks `**********`, placeholder keeps it (StripSecretsUtils.java:59,98-130; RepresentationToModel.java:1240-1253).
